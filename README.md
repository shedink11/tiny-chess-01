A real chess engine in 4 KB of Python: 0x88 board, negamax alpha-beta with iterative deepening (depths 1–7), quiescence search, MVV-LVA + killer move ordering, a Zobrist transposition table, null-move pruning, and a phase-interpolated piece-square evaluation. It plays through the make.fun env, one game after another, and exits when every game is over. Practice trial-0 Elo 1191.

## Run it

```sh
python3 main.py
```
